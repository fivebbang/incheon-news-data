# incheon-news-data

인천체육회 뉴스브리핑(`인천체육회_뉴스브리핑.html`)의 "새로고침" 기능이 참조하는 데이터 저장소입니다.

- `latest.json`: 매일 아침 스케줄 작업이 끝날 때마다 자동으로 갱신되는 최신 뉴스 데이터입니다.
- 이 저장소는 GitHub Pages를 통해 `https://fivebbang.github.io/incheon-news-data/latest.json` 주소로 공개되며, 브리핑 HTML 파일을 받은 누구나(별도 로그인 없이) 그 주소로 최신 데이터를 가져올 수 있습니다.
- 이 저장소에는 민감한 개인정보나 내부 자료를 올리지 않습니다. 공개된 뉴스 기사 요약만 포함됩니다.
